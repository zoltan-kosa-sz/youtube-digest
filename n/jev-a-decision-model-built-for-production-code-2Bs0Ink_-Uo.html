Jev: a decision model built for production code

2026-09-20 / Watch

Use

  1. Replace expensive LLM guards and tool routers with Jev — Instead of spinning up GPT/Claude for yes/no decisions on ticket priority, fraud risk, or tool selection, send typed questions to Jev, get probabilities back, and automate safely at 10–20x lower cost.
  2. Route agent tool calls via fast classification — Use Jev to answer "which tool should this agent call?" or "is this urgent?" in parallel across multiple options (20–200x faster than LLM per decision), letting agents move at machine speed instead of waiting for token generation.
  3. Evaluate whether to escalate or decide alone — Jev returns confidence scores with every answer, so your code can choose: above 95% confidence, run it autonomously; below 70%, hand it to a human or a reasoning LLM.

Bottom line

Jev is a foundational model from TypeSafe AI that returns typed decisions with calibrated probabilities instead of text — enabling fast, cheap decision-making for code agents and production systems. It's not a replacement for reasoning models like Claude, but a specialized tool for the classification, routing, and guard-rail decisions that sit in the hot path of production workflows.

Key ideas

  • System 1 thinking in code instead of System 2 — Jev mirrors Kahneman's "System 1" (fast, intuitive) by returning probabilities in parallel instead of autoregressively generating tokens one at a time; no explanation, no hallucination, just decisions.5:11
  • Purpose-built for routing and guards, not chat — It can't produce text and won't explain itself; it answers typed yes/no, choice, and score questions for tool routing, ticket triage, and verification at 20–200x cheaper and faster than GPT/Claude for those tasks.0:30
  • Vercel saw 6x speed and 10–20x cost savings — Real-world: Vercel replaced Gemini 2.5 Flash Lite with Jev for classification, gained 6x speed, near-perfect accuracy, and paid 10–20x less; the model excels when you don't need prose, only decisions.2:04
  • Parallel evaluation cuts latency in production loops — Jev evaluates all questions at once instead of looping through sequential requests; smart-home commands that took hundreds of milliseconds now return in 185ms, critical for games, robots, and real-time agents.5:43
  • Confidence scores enable safe automation — Each decision includes calibrated probability, letting code choose: automate high-confidence answers, escalate low-confidence ones, or route to a reasoning model; schema-constrained outputs eliminate hallucination risk.8:19
  • Fits the gap between brittle logic and unreliable agents — Deterministic if-then-else systems fail on nuance; agentic reasoning hallucinates and drifts. Jev handles classification and routing reliably and fast, letting you reserve expensive LLM reasoning for cases that actually need it.4:39
