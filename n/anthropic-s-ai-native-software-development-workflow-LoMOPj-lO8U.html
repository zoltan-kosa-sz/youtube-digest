Anthropic's AI-native software development workflow

Switch Dimension (Rob Shocks) / 2026-09-11 / Watch

Use

  1. Try the artifact chain on your next feature: create an `intent/` folder, have Claude interview you until it can write `intent.md`, then generate `spec.md` and `plan.md` from it before touching code.
  2. Write `plan.md` so it's self-sufficient — detailed enough that a different agent (no memory of the planning conversation) could implement it unaided. Test this deliberately since sub-agents/worktrees mean no single agent sees the whole thread.
  3. Before trusting "auto mode" for autonomous building, lock down permissions (allowed folders, packages, web sources) first — the video frames this as the prerequisite for speed, not optional cleanup.

Bottom line

Anthropic's AI-native SDLC playbook reframes the bottleneck: agents made coding fast, so now planning, review, testing, deployment and maintenance are the slow steps — and it formalizes each stage as a git-committed, machine-readable artifact (intent.md → spec.md → plan.md → PR → incident record) so any agent or human can pick up work without the original conversation.

Key ideas

  • intent.md is written by "the originator," not a specialist — a customer's bug report, a PM's feature idea, a dev's process fix. A product owner then triages the resulting backlog of intent files.
  • Each stage hands off an artifact, not a conversation — because separate (sub-)agents work different stages, plan.md must stand alone without reference back to intent.md or spec.md.
  • Testing shifts left of the human: agents write tests, lint, and even browser-test with screenshots (Playwright-style) before a human reviewer ever looks, meant to compress the traditional QA wait.
  • Continuous evals guard against regressions — a fixed set of past issues gets re-run whenever a model, skill, or scale changes, to catch AI-SDLC regressions early.
  • Deploy and maintain get their own agent + policy layer: a separate Claude instance reviews PRs against security/style policy; hooks can gate deployment on human approval.
  • Maintenance becomes proactive, not reactive: an alert, ticket, or Slack message can trigger Claude to diagnose and draft its own intent.md before a human is even paged — the most speculative part of the playbook, per the presenter himself.
